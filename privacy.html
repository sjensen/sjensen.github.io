Privacy Policy

Hermes Personal Assistant — single-user, locally operated software

This policy describes how Hermes Personal Assistant ("the application") handles Google user data. The application is used by exactly one person: the individual who installs and runs it on their own computer ("the owner").

What data the application accesses

  • Gmail — message metadata and content, read to summarize, search, and locate items the owner asks about; send access, used only for messages the owner explicitly approves
  • Google Calendar — events, to build the owner's schedule and detect conflicts, and to create or change events at the owner's request
  • Google Tasks — task lists, to read and update the owner's tasks
  • Google Docs and Drive — read-only access to files the owner names or searches for
  • Google account identity — the email address of the account being accessed

Where the data goes

Google user data is processed on the owner's own computer. It is not transmitted to, stored on, or processed by any server operated by the author of this application. The application has no backend service, no database, and no analytics.

Content that the owner chooses to send to a language-model provider for processing is transmitted directly from the owner's machine to that provider under the owner's own account and that provider's terms. The owner selects and configures that provider.

Storage and retention

  • An OAuth credential (access and refresh token) is stored in a file on the owner's computer, readable only by the owner's operating-system user account
  • Copies of message and calendar content may exist in local logs and local databases created by the application, retained only as long as the owner keeps them
  • No Google user data is retained by any third party on the application's behalf

Sharing

The application does not sell, rent, trade, or transfer Google user data to any third party. It does not use Google user data for advertising, profiling, or training models. It does not permit humans to read Google user data except the owner, or where required by law.

Limited Use

The application's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access and deleting data

The owner can revoke the application's access at any time at myaccount.google.com/permissions. Revoking access immediately invalidates the stored credential. To delete locally stored data, the owner deletes the credential file and the application's local data directory on their computer.

To request deletion or ask any question about this policy, email scott.jensen2@gmail.com. Requests are answered within 30 days.

Children

The application is not directed to anyone under 13 and has no users other than its owner.

Changes

Material changes to this policy will be posted on this page with a new "last updated" date.

Hermes Personal Assistant

A private automation assistant for one person — its owner.

Hermes is a personal software agent that runs on its owner's own computer. It connects to that owner's own Google account to read email and calendar data and to produce a daily briefing, schedule reminders, and track tasks. There is no website, no sign-up, no public account system, and no other users.

What it does

  • Reads the owner's Gmail to summarize the day's messages and flag items needing attention
  • Reads the owner's Google Calendar to assemble a daily schedule and flag conflicts
  • Creates and updates events and tasks on that same account when the owner asks
  • Sends email from the owner's account, only when the owner explicitly approves each message
  • Reads Google Docs and Drive files that the owner names

Who can use it

One person. Access is granted to the Google account of the individual who runs the software. The application is not distributed, not published to any app store, and not offered as a service to anyone else.

How it is designed

  • Runs locally on the owner's machine; Google data is processed there
  • Holds a long-lived OAuth credential in a file readable only by the owner's user account
  • Requests read access to mail, calendar, Docs and Drive, plus send access for approved mail only
  • Never sells, shares, or transfers Google user data to any third party

Hermes Personal Assistant

A private desktop application for one person — its owner.

Purpose

Hermes Personal Assistant ("the application") is a personal productivity tool that runs locally on its owner's own computer. Its single purpose is to help that one individual keep track of their own email, calendar, tasks, and documents by producing a daily briefing, surfacing items that need attention, and carrying out scheduling and task actions the owner explicitly requests.

The application connects only to the Google account of the person who installs and runs it. It has no public sign-up, no multi-user accounts, no web service, and no other users. Everything it does is initiated by its owner on the owner's own machine.

What it does

  • Reads the owner's Gmail to summarize the day's messages and flag items needing attention
  • Reads the owner's Google Calendar to assemble a daily schedule and identify conflicts
  • Creates, updates, and deletes calendar events and tasks on that same account when the owner asks
  • Reads and updates the owner's Google Tasks lists
  • Reads Google Docs and Drive files that the owner names or searches for
  • Sends email from the owner's account, only after the owner explicitly approves each message

How it works

  • Installed and run by the owner on the owner's own computer; there is no server operated by the author of this application
  • Authorizes through Google OAuth using the owner's own credentials and stored consent
  • Keeps its OAuth credential in a file readable only by the owner's operating-system account
  • Requests read access to Gmail, Calendar, Tasks, Docs, and Drive, plus gmail.send for messages the owner approves, and gmail.settings.basic to manage the owner's own mail filters
  • Never sells, rents, or shares Google user data with any third party, and never uses it for advertising or profiling

Google API compliance

This application's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Artificial intelligence

The application uses a large language model to summarize and draft text for its owner. It does not use Google APIs or Google user data to generate, create, or distribute AI-generated non-consensual intimate imagery (NCII), or any other prohibited content. It does not use Google user data to develop, improve, or train generalized artificial intelligence or machine-learning models.
